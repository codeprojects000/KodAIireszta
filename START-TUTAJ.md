# Aktualizacja strony na GitHub Pages
Rozpakuj ZIP. Wgraj pliki i foldery do głównego katalogu repozytorium KodAIireszta, nadpisując poprzednie wersje. Zachowaj folder assets/responsive. Nie wgrywaj archiwum ZIP jako pliku strony. Hosting pozostaje w GitHub Pages, Source: GitHub Actions. Automat Sync portal content publikuje zmiany. Nie zmieniaj DNS, domeny ani ustawień HTTPS. Nie używamy Cloudflare.
